# reactCV

> My CV built with React and TypeScript.

## Overview

**reactCV** is a web application that presents my CV, built entirely using React and TypeScript.  
It demonstrates my experience, education, skills, and projects in a modern, visually appealing UI.

---

## Features

- 100% TypeScript codebase
- All CV sections: work, education, skills, languages, and more
- Component-based architecture for clean and manageable code
- Easy to maintain and update

---

## Tech Stack

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [CSS Modules | Styled Components | Tailwind CSS]
- [Vite | Create React App |]
---

## Installation

```bash
git clone https://github.com/LasperKaine/reactCV.git
cd reactCV
npm install
npm run dev    # or npm start
```
